# DAX-AND-DATA-VISUALIZATION
# Overview
A Power BI analysis covering e-commerce transactions, customer orders, and global layoffs across data cleaning, visual modeling, and DAX calculations.
# Key Deliverables
Visuals:
1. Clustered Column Chart
2. Line Chart
3. Pie Chart

DAX Measures:
1. Total Sales: SUM()
2. Total Rows: COUNTROWS()
3. Valid Records: COUNT()
4. Missing Values: COUNTROWS(FILTER(..., ISBLANK(...)))
5. Min / Max: MIN() and MAX()
